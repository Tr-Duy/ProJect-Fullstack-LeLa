# LeLa Project Memory & System Architecture

## 1. Tổng quan Kiến Trúc Dự Án (Tech Stack)
- **Monorepo / Thư mục chính**:
  - `LeLa_BE`: Spring Boot 3, Java 21, Spring Security (OAuth2 Google / JWT), Spring Data JPA, MySQL 8.0, Flyway Migration, WebSocket, Gemini API SDK. Base Context Path: `/api/v1`. Cổng mặc định: `8080`.
  - `LeLa_FE`: React 18, TypeScript, Vite, Tailwind CSS, Ant Design, Lucide Icons, Axios. Cổng mặc định: `5173`.
  - `LeLa_Mobile`: React Native (Expo SDK), TypeScript, SecureStore, Expo AV / Speech.
- **Nhận diện thương hiệu & UX**:
  - Màu chủ đạo: Cam LeLa (`#EA580C` / Tailwind `orange-600` / `amber-500`).
  - Tuyệt đối không tự ý đổi sang tông màu khác (như xanh navy/teal) và không tự ý bịa đặt quy tắc khóa tính năng/giới hạn khi chưa có yêu cầu từ người dùng.

## 2. Các Module Chính & Tình Trạng Hiện Tại

### A. Phân Hệ Luyện Nói AI (Voice Conversation)
- **Frontend Pages/Components**:
  - `LeLa_FE/src/features/voice-conversation/pages/VoiceConversationPage.tsx`: Màn hình giới thiệu, chọn kịch bản và bắt đầu cuộc gọi.
  - `LeLa_FE/src/features/voice-conversation/components/VoiceCallRoom.tsx`: Phòng gọi thoại thời gian thực.
  - `LeLa_FE/src/features/voice-conversation/hooks/useSpeechRecognition.ts`: Quản lý Web Speech STT, chống dội âm (Echo Guard), nhận diện ngắt câu thông minh.
  - `LeLa_FE/src/features/voice-conversation/hooks/useSpeechSynthesis.ts`: TTS giọng đọc tiếng Anh tự nhiên, xử lý đệm `50ms` sau `cancel()` để tránh nghẽn queue trong Chrome.
- **Backend Endpoints & Services**:
  - Controller: `VoiceConversationController.java` (`/api/v1/voice-conversation`)
    - `GET /status`: Lấy trạng thái quota, level học viên, phiên đang dở dang.
    - `GET /scenarios`: Lấy danh sách kịch bản hội thoại khả dụng theo level.
    - `POST /start`: Khởi tạo phiên đàm thoại mới (`VoiceStartResponse`).
    - `POST /turn`: Gửi lượt nói của học viên, nhận phản hồi AI (`VoiceTurnResponse`).
    - `POST /finish`: Kết thúc phiên và xuất báo cáo (`VoiceReportResponse`).
  - Service:
    - `VoiceConversationServiceImpl.java`: Điều phối luồng đàm thoại, quota, target words.
    - `VoiceAiService.java`: Giao tiếp Gemini API, xử lý ngữ cảnh STT misheard words, sinh câu thoại và đánh giá phát âm/ngữ pháp.
- **Cấu trúc DTO Mới Nhất**:
  - `VoiceTurnResponse`: `turnNumber`, `aiReply`, `grammarErrors`, `correctedSentence`, `quickSuggestion`, `updatedTargetWords`, `validTurnCount`, `sessionEnded`, `endReason`, `userEvaluation`.
  - `UserEvaluationDto`: `score` (Integer), `feedback` (String), `grammarCheck` (String), `suggestedImprovement` (String).

### B. Khảo Thí & Đánh Giá Năng Lực (Assessment & Quizzes)
- `FinalLevelAssessmentController.java`: Bài thi kiểm tra đầu ra / kết thúc cấp độ (`/final-level-tests`).
- `QuizController.java`: Quản lý kho bài thi, quiz thực hành, placement test.
- `OnboardingController.java`: Khảo sát ban đầu và phân cấp level học viên.

### C. Học Từ Vựng & Flashcard
- Hệ thống Spaced Repetition (SRS), Deck, Flashcard, Foundation Words.

## 3. Các Bug Quan Trọng Đã Được Khắc Phục (Bug History)
1. **Echo Loop (Micro tự thu tiếng loa AI)**:
   - Dập tắt micro ngay lập tức khi bắt đầu phát âm TTS (`stopListening()`, `abortAndReset()`).
   - Thêm bộ đệm an toàn `400ms` sau khi TTS phát xong để triệt tiêu tiếng vang trước khi mở lại micro.
2. **Kẹt chữ cũ (Stale Transcript)**:
   - Reset sạch sẽ `transcript` khi gửi lượt thoại (`resetTranscript()`).
   - Ràng buộc hiển thị chữ `"Bạn đang nói: ..."` bằng điều kiện: `isListening && transcript.trim().length > 0`.
3. **AI bị câm / không tự động đọc câu hỏi mới**:
   - Thêm đệm `50ms` giữa `speechSynthesis.cancel()` và `speak()` để Chrome không bị treo TTS.
   - Thêm nút Loa Replay bên cạnh câu thoại AI để người dùng có thể chủ động nghe lại bất cứ lúc nào.
4. **Phản hồi đánh giá tức thì (Feedback Loop)**:
   - Backend hướng dẫn Gemini xuất cấu trúc `userEvaluation`.
   - Frontend hiển thị `Quick Feedback Card` ấm áp chuẩn tông Cam LeLa ngay dưới câu thoại AI.
